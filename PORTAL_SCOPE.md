# Portal Flagship Scope & Ecosystem Separation

## Overview

The Tesseract Portal is the singular flagship conversational engine and cognitive operating interface for the operator's sovereign ecosystem. It concentrates all advanced intelligence layers (Trifecta multi-agent orchestration, cMAP session awareness, evolutionary tuning, and dynamic personality manifestation) into one focused interface.

Other systems in the ecosystem operate as independent endpoints and services:
- **Tesseract Mirror** (`nexinus.net`): Dedicated Pythagorean geometry scoring and reflection engine.
- **Exinus Clarity Suite** (`exinus.one`): Suite featuring GED Tutor, Hidden Gems, Public Defender Pro, Task Force Pro, and deterministic modes (Core, Expand, Ascend, Transcend, Light Warrior).
- **Tesseract Terminus** (`universaltruth.life`): High-security root terminal and validation layer.
- **Monarch Operating System**: Sovereign Debian-based OS and bootable ISO.

## Portal Scope within this Application

This repository houses exclusively the **Portal** workspace. Non-Portal utilities (such as separate Knowledge Graph management, standalone Ontology editors, and Mirror submission forms) are removed from the active sidebar navigation so the operator experiences a singular, uninterrupted cognitive command console.
